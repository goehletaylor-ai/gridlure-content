# Gridlure content

Themed daily puzzles, published to the Gridlure app. The app downloads `days.json`
from this repo's GitHub Pages site.

Rules:

- Publish a day at least a day before it releases (6:00 AM Pacific). The app only
  adopts a day before its release; after that it's frozen on every phone, and a day
  published too late is ignored.
- Every picture must be solvable by logic alone. The app checks and skips anything
  that isn't, or that's malformed.
- A broken file is ignored entirely, so a typo can't wipe out scheduled days.

Format: the same as `ThemedDays.json` in the app. See `docs/DailySystemPlan.md` in the
app repo.
